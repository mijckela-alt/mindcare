# MindCare — сайт психологической клиники

Одностраничный сайт частной психологической клиники в Одессе. Чистая статика: HTML, CSS и немного
JavaScript, без сборки и зависимостей.

## Структура

| Файл | Назначение |
| --- | --- |
| `index.html` | Вся разметка страницы и модальное окно записи |
| `styles.css` | Стили и адаптив (брейкпоинты 980px и 640px) |
| `app.js` | Бургер-меню, аккордеон FAQ, модальное окно и валидация формы |

## Блоки страницы

Главный экран → О клинике (преимущества и конфиденциальность) → Услуги с ценами → Специалисты →
Отзывы → FAQ → Контакты с картой. Кнопки «Записаться» во всех блоках открывают одно модальное окно;
кнопки в карточках услуг и специалистов подставляют в форму соответствующую услугу или специалиста.

## Запуск локально

Достаточно открыть `index.html` в браузере. Либо поднять локальный сервер:

```powershell
python -m http.server 8090
```

Затем открыть <http://localhost:8090>.

## Форма записи

Форма работает **только на стороне клиента**: проверяет имя и телефон и показывает экран «Спасибо».
Заявки никуда не отправляются — это сделано намеренно.

Чтобы заявки приходили, например, в Telegram, нужен минимальный бэкенд: страница отправляет JSON на
свой эндпоинт, а сервер уже обращается к API Telegram. Токен бота при этом должен оставаться на
сервере — в `app.js` его класть нельзя.

## Что заменить на реальные данные

- Тексты отзывов, имена и опыт специалистов — сейчас это заглушки.
- Цены услуг (`900 / 1400 / 800 грн`).
- Фотографии психологов: сейчас это CSS-кружки с инициалами, изображений в проекте нет.
